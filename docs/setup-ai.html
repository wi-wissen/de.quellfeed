Quell Feed

Set up AI on your phone

Quell Feed can summarize long articles, translate them, and filter your feeds by your own wishes — if you switch that on. There is no account and no subscription behind it: you bring your own API key from an AI provider (think of it as a prepaid phone card — how to get one is explained below), and the app talks to that provider directly. Without a key the AI features simply stay off; everything else in the app works without them.

Where do I get a key?

A key is like a prepaid phone card for AI: you create it once in the provider's dashboard, put a few euros on the account, and the app uses it only when you tap Summarize, Translate, or when a feed filter runs.

OpenRouter (recommended — one key, many models)
  1. Go to openrouter.ai and sign in (Google/GitHub works).
  2. Top-right menu → Credits → add a small amount (5 € lasts a long time — a summary costs fractions of a cent).
  3. Top-right menu → Keys → Create key, give it a name like “Quell Feed”.
  4. Copy the key (starts with sk-or-) into the field above. Done.
OpenAI
  1. Go to platform.openai.com and sign in (this is the developer site — a ChatGPT subscription is a different product and not needed).
  2. Settings → Billing → add a payment method or prepaid credit.
  3. API keys → Create new secret key.
  4. Copy the key (starts with sk-) into the field above — it is shown only once.
